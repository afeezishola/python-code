# Python 3-PIN Attempt Exercise

## Programming Question

Write a Python program that asks the user to enter a PIN to access an account.

The correct PIN is `4321`. The user should be given a maximum of 3 attempts.

### Requirements

- If the user enters `4321`, display `Access granted` and stop the program.
- If the PIN is incorrect, display `Incorrect PIN` and allow the user to try again.
- After 3 incorrect attempts, display `Account locked` and stop the program.
- Use a `while` loop to keep asking for the PIN until access is granted or the account is locked.

## Solution

The solution is in `3pin_attempt.py`.
