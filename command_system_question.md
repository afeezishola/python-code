# Challenge — Command System

You are building a small command-line system for a software application.

The program should continuously ask the user to enter a command.

The available commands are:

- `"help"` → display `"Available commands: help, status, quit"`
- `"status"` → display `"System is running"`
- `"quit"` → display `"Program closed"` and stop the program
- Anything else → display `"Unknown command"`
